## 0. The one thing to understand before anything else

Your headline — **IPC-named 97.0% vs BNS-named 51.5%** — was measured with the
corpus filter **switched off**: the meaning-based search on its own, no Router.

With your deployed Router **on**, a question that names its code is sent to the
right book **every time**:

| Paired questions, Router on | Routed to the correct code |
|---|---|
| name the IPC | **33 / 33** |
| name the BNS | **33 / 33** |

`results/routing_confusion.csv`, metric `paired_routing_accuracy_*`. ✅ verified.

So the honest framing — and it is a stronger one — is:

> Meaning-based search, by itself, cannot tell the two codes apart: it favours the
> repealed one. The deployed system is protected only by a keyword filter, and that
> filter works only when the user names the code. **Ordinary people do not name
> codes** — which is exactly where retrieval collapses to 15.0% and no answer is
> fully grounded.

If an examiner asks *"does your deployed system fail this way?"*, the answer is:
*"Not when the code is named — the router catches it. It fails when nothing is named,
which is the access-to-justice case."* Say that before they ask.

## 10. Agent-by-agent reference — for studying

Execution order. Line numbers are from the current code.

### `POST /query` — `app.py:125-315`

**Request** (untyped dict): `query` (required), `query_id` (default `"adhoc"`),
`style` (accepted, **unused**), `intervention` (`baseline` | `date` | `mapper` |
`both`; else env `INTERVENTION`; else `baseline`), `reference_date` (ISO; default
today; used only off-baseline). Query param `format=json|html`.

**Response:** `answer`, `citations[{source, page, snippet ≤ 200 chars}]`,
`confidence`, `refused`, `prompt_variant` (HIGH/MEDIUM/LOW/REFUSED), `llm_ok`,
`llm_error`, `gen_provider`, `gen_model`, `prompt_tokens`, `completion_tokens`,
`paralegal_context{scenario, issues, persona, complexity, urgency,
financial_status, missing_facts}`, `report_url` or `report_error`,
`citation_audit{n_cited, n_grounded, ungrounded_rate, ungrounded_rate_lenient, …}`,
`req_id`. **Not returned:** refusal reason, retrieval scores, decision path.

**Other endpoints:** `GET /healthz`, `GET /diag/env` (runs `config.check()`),
`POST /ingest`, `/static`.

### A · Intake — `agents/intake.py` · **LLM**

- **In:** the query string.
- **Out:** `CaseContext` — `original_query, scenario, user_persona, urgency,
  financial_status, complexity, predicted_legal_domain, legal_issues[],
  missing_facts[], llm_ok, fallback_used, llm_error, raw_response_chars`.
- **Steps:** one JSON-mode call (max_tokens 1500) → slice first `{` to last `}` →
  `json.loads` → map keys with aliases and defaults → 16 regexes can force
  `user_persona = "Paralegal"`.
- **Model:** `google/gemini-3.7-flash`, temperature 0, seed 20260822, provider
  pinned, fallbacks off.
- **Failure:** any exception → hard-coded defaults, `fallback_used = True`.
- **Known defect:** domain and issues are lost on the *success* path (B1).

### B · Router — `agents/router.py` · **deterministic**

- **In:** `CaseContext`. **Out:** `QueryPlan` — `original_query,
  rewritten_query, intent, target_corpus, target_corpora[], entities,
  boost_terms, decision_path`.
- **Steps:** substring-scan the query against `ACT_MAP` (IPC→IPC, BNS→BNS,
  CrPC/BNSS→CRPC, CPA→CPA). One match → filter; several → no filter; none →
  `no_match`, no filter. Extract `Section N` entities. Rewrite =
  issues + entities + query.
- **In the logs:** `act_map_single` 605, `no_match` 254. The domain fallback never
  fired.

### C · Interventions — `app.py:175-199` · **deterministic**, off by default

- `date` / `mapper` / `both` → `core.dates.resolve(query, reference_date)` →
  era `IPC_ERA` | `BNS_ERA` | `BOTH_ERAS` | `UNKNOWN`.
- `mapper` / `both` → `core.statute_mapper.map_query(query, era)` → replaces
  `plan.target_corpora`. Does **not** change `entities` or `rewritten_query` (B5).

### D · Retrieval + confidence — `agents/retriever.py` · embedding call + rules

1. Embed `rewritten_query` (`openai/text-embedding-3-small`, 1536-d).
2. Filter: one corpus → match; several → match-any.
3. Qdrant search, `limit = 15`.
4. Zero results with a filter → retry unfiltered (never fired).
5. Rerank: passages containing an entity first.
6. Threshold `max(top − 0.15, 0.35)`; if fewer than 3 survive, force the first 3.
7. Confidence from all 15 scores:
   - `m` = mean of top 5
   - `gap` = top-1 minus top-5; `g = min(gap / 0.3, 1)`
   - `e` = share of entities found in the top 5, or 0.5 if none
   - `C = min(0.55m + 0.15(1 − g) + 0.30e, 1)`
8. Refusal gate: no chunks → every named Act outside the index → max < 0.25.
   **Never fired in 859 runs.**

### E · Answer — `agents/answer.py` · **LLM**

- **In:** query, `RetrievalResult`.
- **Tier:** C < 0.38 LOW (adds a "don't cite unless retrieved" disclaimer) ·
  < 0.55 MEDIUM · else HIGH.
- **Prompt:** query + every filtered passage in full.
- **Model:** as Intake, plain text (no JSON mode, no validator).
- **Out:** `answer, citations[snippet ≤ 200], confidence, refused,
  prompt_variant, llm_ok, …`.
- **Failure:** an apology string; `refused` stays False.

### F · Reporter — `agents/reporter.py` · **deterministic**, fpdf2

Four sections: Case Summary, Relevant Statutes (`plan.entities`), Legal Analysis,
References. Latin-1 only. Runs before the verifier.

### G · Verifier — `app.py:280-299` → `core/verifier.audit_answer`

Extracts provisions cited in the answer and checks each against the retrieved text
(B6, B7). Logs `cited, grounded, ungrounded, ungrounded_rate` (strict — the
headline) and `ungrounded_rate_lenient`.

### H · Run logger — `core/run_logger.py`

`runs/<date>_<sha>/meta.json` (git sha, dirty flag, models, config) and
